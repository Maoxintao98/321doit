# 321Doit 0.8 build 11

## 中文发布说明

0.8 build 11 修复了首页和设置界面的交互问题，并针对启动、滚动和指针响应进行了专项性能优化：

- 每张最近项目卡片现在都有独立的叉号，可直接从最近项目列表移除；不会删除磁盘上的项目文件。
- Mira AI 与“新建项目”采用统一的高度、圆角和按钮结构，主次操作层级更清晰。
- 设置侧栏改为单一选中状态，不再出现蓝底深色字、无底白字或左右内容不同步。
- 最近项目的可用性检查改为后台缓存，SwiftUI 重绘不再同步访问 OneDrive、离线磁盘或失效路径。
- 启动页不再预先同步加载上次项目；只有用户选择项目后才读取项目数据。
- 首页高频卡片移除重复的实时材质模糊层，降低窗口滚动、悬停和重绘时的 GPU 合成开销。

正式离线安装器包含经过校验的 Universal 2 依赖：

- 321Doit（arm64 + x86_64）
- FFmpeg / FFprobe 8.1.2（arm64 + x86_64）
- OpenCode 1.18.15（arm64 + x86_64）

> **Intel 支持说明：0.8 build 11 是最后一个同时支持 Intel 与 Apple Silicon Mac 的 Universal 2 版本。从下一个 Build 开始，321Doit 正式发布包将只支持 Apple Silicon（arm64）。Intel 用户可以继续使用 build 11，但不会再收到后续应用版本。**

当前发布通道继续使用 ad-hoc App/DMG 签名和无签名 PKG，尚未进行 Apple 公证。请从本仓库 GitHub Releases 下载，并核对随附的 SHA-256 文件。

## English release notes

0.8 build 11 fixes launch-screen and Preferences interactions and delivers targeted startup, scrolling, and pointer-responsiveness improvements:

- Every recent-project card now has its own remove button. Removing an entry does not delete the project from disk.
- Mira AI and New Project now share one height, corner radius, and control structure with a clear primary/secondary hierarchy.
- Preferences now uses a single selection state, eliminating mismatched content and low-contrast selected-row colors.
- Recent-project availability is checked and cached off the main thread; SwiftUI redraws no longer synchronously probe OneDrive, disconnected disks, or stale paths.
- The launch screen no longer opens the previous project synchronously; project data is loaded only after the user chooses a project.
- High-frequency launch cards no longer stack live material blur layers, reducing GPU compositing work during scrolling, hovering, and window redraws.

The formal offline installer contains verified Universal 2 dependencies:

- 321Doit (arm64 + x86_64)
- FFmpeg / FFprobe 8.1.2 (arm64 + x86_64)
- OpenCode 1.18.15 (arm64 + x86_64)

> **Intel support notice: 0.8 build 11 is the final Universal 2 release for both Intel and Apple Silicon Macs. Starting with the next build, formal 321Doit releases will support Apple Silicon (arm64) only. Intel users can remain on build 11, but will not receive later application releases.**

The current channel still uses ad-hoc App/DMG signing and an unsigned PKG; it is not Apple-notarized. Download from this repository's GitHub Releases and verify the accompanying SHA-256 file.
