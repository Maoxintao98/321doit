# 321Doit 0.8 build 9

## 中文发布说明

0.8 build 9 更新了 Liquid Glass 工作站外壳与设置面板，修复了剧本输入提示词、拍摄日历和拷卡路径选择界面，并将正式离线依赖收口为经过校验的 Universal 2 载荷：

- FFmpeg 8.1.2（arm64 + x86_64）
- FFprobe 8.1.2（arm64 + x86_64）
- OpenCode 1.18.15（arm64 + x86_64）

安装器不需要 Homebrew，也不会在安装时联网下载依赖。321Doit 会优先使用随 App 发布并经过验证的依赖版本。

> **Intel 支持说明：0.8 build 9 是最后一个同时支持 Intel 与 Apple Silicon Mac 的 Universal 2 版本。从下一个版本开始，321Doit 正式发布包将只支持 Apple Silicon（arm64）。Intel 用户可以继续使用 build 9，但不会再收到后续应用版本。**

当前发布通道继续使用 ad-hoc App/DMG 签名和无签名 PKG，尚未进行 Apple 公证。请从本仓库 GitHub Releases 下载，并核对随附的 SHA-256 文件。

## English release notes

0.8 build 9 refreshes the Liquid Glass workstation shell and Preferences, fixes screenplay placeholders, simplifies the production calendar, and polishes the offload path controls. Its formal offline payload now contains verified Universal 2 dependencies:

- FFmpeg 8.1.2 (arm64 + x86_64)
- FFprobe 8.1.2 (arm64 + x86_64)
- OpenCode 1.18.15 (arm64 + x86_64)

The installer requires neither Homebrew nor a network dependency download. 321Doit prefers the release-pinned tools embedded in the app.

> **Intel support notice: 0.8 build 9 is the final Universal 2 release for both Intel and Apple Silicon Macs. Starting with the next version, formal 321Doit releases will support Apple Silicon (arm64) only. Intel users can remain on build 9, but will not receive later application releases.**

The current channel still uses ad-hoc App/DMG signing and an unsigned PKG; it is not Apple-notarized. Download from this repository's GitHub Releases and verify the accompanying SHA-256 file.
